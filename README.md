# AI个人财务管理系统

.NET Framework 4.8 WinForms 桌面应用，支持记账、统计、预算、模板管理、CSV导入导出和 AI 智能分析。

## 功能

| 模块 | 说明 |
|------|------|
| 登录/注册 | 用户名密码登录，记住登录状态 |
| 仪表盘 | 当月收支概览 + 分类饼图 |
| 记账管理 | 新增/编辑/删除记录，分类筛选，AI 文本解析导入 |
| 统计面板 | 收支饼图、趋势条形图，多维度（日/月/季/年）查询 |
| 预算管理 | 月度/年度预算，分类预警，AI 预算建议 |
| 模板管理 | 常用记账模板，一键预填 |
| 数据管理 | 日期/分类筛选查询，CSV 导入导出，清空记录 |
| 设置页 | 修改用户名/密码，AI API 配置 |
| AI 分析 | DeepSeek/OpenAI 消费分析、预算建议、文本智能解析 |

## 技术栈

- **框架**：.NET Framework 4.8 + WinForms
- **数据库**：SQL Server LocalDB
- **AI**：DeepSeek API（兼容 OpenAI 格式）
- **测试**：MSTest + Moq（123 个测试全通过）

## 快速开始

1. Clone 仓库
2. VS 2022 打开 `FinanceManager.slnx`
3. 生成 → 生成解决方案
4. 运行 `FinanceManager.exe`
5. 注册账号 → 导入 `test.csv` 体验

## AI 配置

设置页 → 填写 DeepSeek API Key（[申请地址](https://platform.deepseek.com)）→ 保存
